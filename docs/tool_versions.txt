## Verification Notes

The project uses the following intended toolchain roles:

| Tool | Role |
|---|---|
| SystemVerilog | RTL design |
| Verilator | RTL linting and simulation |
| GTKWave | Waveform inspection |
| Yosys | Logic synthesis and synthesis reporting |
| OpenROAD | Floorplanning, placement, CTS, routing, and physical flow |
| OpenSTA | Static timing analysis |
| KLayout / Magic | Layout inspection and physical verification |
| Python | Automation, report parsing, data collection, and plotting |
| Tcl | Flow control and tool scripting |
